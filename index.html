Bulk Metadata Editing for Media Files

Metadata are the things you normally never see, but always need. If they can be written into the file, they're always there when you need them, so you don't have to rely on scraping them from somewhere else. These tools were created to help you see, correct, and update whatever information is written into your media files.

The ƆBZ Redactor

Edit ComicInfo.xml metadata in CBZ comic archives — title, series, credits, and more — plus lookups against Comic Vine, the Grand Comics Database, and Bedetheque.

The ƎPUB Redactor

Bulk-edit EPUB ebook metadata for Kobo and other e-readers, with Google Books / Open Library lookups, cover generation, and format conversion via Calibre.

The ɯP3 Redactor

Check MP3 file integrity, detect BPM and musical key, measure loudness, and bulk-edit tags across a whole library at once.

The Ʌideo Redactor

Bulk-edit MKV/MP4 metadata with TMDB lookups, season/episode matching, subtitle fetching, and poster art — for movies, TV, and everything in between.

Why these exist

Embedded metadata is growing more and more important, but there are very few programs available to the private consumer to make these changes on a larger file set.

Following the same editing principles as Mp3tag (Florian Heidenreich, 1999), this suite of tools allows you to change:

  • Comics
  • Books
  • Videos
  • Music in addition to Mp3tag, not as a replacement for it

They all share the redactor_common repo for a unified appearance and functionality. There are enough format-specific differences to keep them as four separate apps rather than one big one.

Formats

Each app edits one native format in place, and can also pull in other formats by converting them first — via the same well-known external tools an mp3tag/Calibre/ffmpeg user would already recognize:
