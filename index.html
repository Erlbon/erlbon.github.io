RIL HUMIN TOOLZ

Free software for your files, books, music and video

A file manager, four metadata editors, a small library server and a cycling data tool. They are written in Python, free to use, open source, and built around the idea that your files are yours: plain folders, plain formats, nothing locked in a database you cannot read.

File manager · Windows

Dossier

A dual-pane file manager: two panels with tabs and one shared selection, safe planned copies and moves, archives and servers shown as folders (SFTP, WebDAV, FTP, OPDS book catalogues, Subsonic music servers, your Tailscale devices), a viewer and an editor, search, duplicates, compare and synchronize, plus a command line and a local MCP server for scripts and AI assistants.
Metadata editors · Windows & Linux

The Redactor Tools

Four apps for bulk-editing the metadata written inside your files: comics (CBZ and ComicInfo.xml), ebooks (EPUB), music (MP3 tags, integrity, key and BPM) and video (MKV and MP4). Lookups online or in databases you build yourself, one-click recipes, duplicate finding, and a command line in each.
Library server · Docker, Windows & Linux

Pluteus

A light book, comic and music server that reads your real folders live: OPDS feeds for reader apps, EPUB, CBZ and PDF readers in the browser, a music and audiobook player, Subsonic, WebDAV and KOReader sync, per-user logins and progress, and no library database to rebuild. MIT-licensed.
Cycling tool · In your browser

Kinderkopje

Season YAML in, Reddit-ready race threads out, built for the r/peloton moderators. Also UCI team ranking snapshots, a race lookup with names, links and rider-age statistics, and a public SQLite database you can query in SQL. It runs in your browser; nothing is uploaded. MIT-licensed.
