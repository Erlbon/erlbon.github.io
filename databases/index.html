The local databases, one by one

Six sources can be turned into an offline database. You download each file yourself, under the source’s own terms; the apps never bundle or fetch them. Five of them are built into a compact database from a dialog in the app’s Tools menu (with progress, and Cancel is safe); the GCD dump is read directly as it is.

SourceAppYou downloadIn the appLicence
GCD data dump ƆBZ current.zip, GCD’s SQLite dump from comics.org (a free account is needed; about 2 GB zipped, about 7 GB unzipped). Tools > GCD Local Database. Point the app at the unzipped .db; there is no build step. CC BY-SA 4.0
ComicRack library ƆBZ Your own ComicDb.xml, plain or zipped. Tools > ComicRack Library Database converts it once (30–40 seconds for 234,000 books). File paths and reading history are never copied. Your own data
Open Library data dumps ƎPUB The editions dump and the authors dump (or the single all-types dump) from openlibrary.org/developers/dumps; the works dump is optional. Tools > Open Library Database. Only editions with a valid ISBN, in the languages you tick; about 2.5 GB for 8 million editions (an estimate). CC0 (public domain)
ISFDB backup ƎPUB backup-MySQL-55-YYYY-MM-DD.zip, the ISFDB’s MySQL backup from isfdb.org (about 340 MB zipped, 1.5 GB of SQL); it needs no unpacking. Tools > ISFDB Database. On the 2025-12-27 backup the build took under two minutes and gave a 154 MB database: 425,000 books (211,000 in a series) and 638,000 editions with an ISBN. It is the source that knows a book’s series and series number. Creative Commons Attribution; credit the ISFDB
MusicBrainz core-data dump ɯP3 mbdump.tar.bz2 from musicbrainz.org (about 7 GB; it needs no unpacking). Tools > MusicBrainz Database. About 5–6 GB on disk and roughly 12 GB free while it builds (estimates). Core tables only: no genre, no cover. CC0 (core data only)
IMDb datasets Ʌideo title.basics.tsv.gz (required) and optionally title.ratings, title.episode and title.akas, from datasets.imdbws.com. Tools > IMDb Database. Roughly 0.6–1 GB with the default options (an estimate). Personal, non-commercial use only

In Redact, the lookup step asks a local database first when one is set up (for ƎPUB: ISFDB, then Open Library), then the online sources for whatever is still empty.

Information courtesy of IMDb (https://www.imdb.com). Used with permission. The ISFDB’s data is licensed under Creative Commons Attribution; the apps credit it under Help > Credits.

All of this is optional. With no key, no database and no network, every app still edits, checks and converts your files. See all sources side by side and the data notices and licences.
