The ƆBZ Redactor

A free CBZ metadata editor for Windows and Linux — read and write ComicInfo.xml without touching the page images, plus opt-in tools for oversized scans and CBR/CBT/CB7 conversion.

Download latest release View source on GitHub

What a CBZ is

A CBZ file is a plain ZIP archive of sequentially-named comic page images, optionally with a ComicInfo.xml metadata file at its root — the de facto standard originating from ComicRack and documented by the Anansi Project. Not every CBZ has one; the ƆBZ Redactor creates one on save if it's missing, rather than requiring it up front. Its field handling was checked directly against ComicTagger's own source to stay compatible with what readers like Kavita actually expect.

Features

  • Load one or many .cbz (or .cbr/.cbt/.cb7) files, or a whole folder, into a sortable, column-configurable table; multi-select for editing, saving, or looking up several issues at once.
  • Bulk edit the full ComicInfo.xml v2.0 field set, plus draft v2.1 fields already understood by ComicTagger and Kavita (Translator, Tags, StoryArcNumber, GTIN) — a field left blank is left untouched, not cleared.
  • Metadata lookups against Comic Vine, the Grand Comics Database, and Bedetheque, each with a cover preview and a confirm-before-write review step, and each matched issue's page recorded in Web.
  • Offline lookups in your own local copies: the GCD's downloadable database (milliseconds per file, no hourly limit), and your own ComicRack library, converted once from its ComicDb.xml — only descriptions of comics are copied, never file paths or reading history.
  • Compare your ComicRack library with the GCD: series and issues the GCD doesn't have, and GCD issues missing credits, characters or a summary your library has — saved as spreadsheets, ready to contribute back.
  • Read Filename Tags: scene-style filenames parsed into series, number, year and title, with bracketed tags sorted into Scan Information, Format and Notes — using pattern rules and a list of ~350 release groups. Only whole bracketed phrases count, so title words are never stripped.
  • Overwrite review: any import that would replace metadata you already have shows old vs. new side by side, per field, per file, with a checkbox for exactly what to keep.
  • Rename / Export Files and its reverse, Parse Filename → Metadata, both built on a %series% %number% - %title%-style pattern using any ComicInfo field.
  • Search/Replace and Case Conversion across any field, with a before/after preview and a per-row apply checkbox.
  • Undo (up to 5 steps) for in-memory metadata edits — bulk edits, lookups, renames, search/replace, and case conversion.
  • Genre and Language quick-pick lists, drag-to-reorder and hideable columns, and a resizable cover-image panel — all persisted across restarts.
  • Size column: each comic's typical page width, color-coded — yellow for low-res (under 1000px), green for acceptable (1000–1599px), orange for oversized (1600px and up). Double-page spreads and a single huge cover don't skew it. A File Size column is available too.
  • Resize Images: shrink oversized pages to a target width (1440px by default), with double-page spreads kept at double width. Optional height limit, optional JPEG or WebP output, and a one-click "only oversized files" mode. Never upscales; export copies or resize in place.
  • Tag Low-Res Scans: marks low-res comics with a Low-res scan tag in ComicInfo.xml so you can find and replace them later — here, or in a comic server like Komga or Kavita.
  • Scanner credit pages: tick a "scanned by" page once and it's remembered; every file containing it is flagged and can have it removed — matched visually, so it's recognised even after resizing or re-encoding.
  • Find Duplicates: the same comic loaded more than once, matched by its pages rather than its name, with the best copy suggested (highest resolution, most pages, best-tagged).
  • Clean Up Archive Contents: pages inside each archive renamed to plain numbers in reading order and taken out of folders — removing release-group names and over-long paths — and junk files (Thumbs.db, .DS_Store, __MACOSX, .nfo, .sfv ...) removed. Pages and ComicInfo.xml untouched.
  • CBR, CBT and CB7 support: list them unconverted and convert from the table, convert automatically on load, or be asked each time. An Ext column shows each file's real format, so a ZIP renamed to .cbr is caught (and converted by a simple copy). Every conversion is verified before anything else happens, and originals are kept or moved to the Recycle Bin — never permanently deleted.

Requirements

Two downloads on each release: a standalone .exe for Windows, and cbzredactor-linux-x86_64.tar.gz for 64-bit Linux (Ubuntu 22.04+, Debian 12+, Fedora 36+, Mint 21+ and the like — unpack and run; settings live in ~/.config/cbzredactor/). No separate Python install needed on either. Full details and the changelog are in the GitHub repository.

Inspirations

Two older tools shaped parts of this one — no code from either is used:

  • ZenCBR by the late Shannon Larratt — the scene-tag handling behind Read Filename Tags (matching whole bracketed phrases against a learned list of release groups) and its name-cleaning rules. The built-in tag list was seeded from a ZenCBR training list.
  • CbxConverter by tomek-o — the Size column and the Resize Images options (height limit, output format, width presets), done here in-process with Pillow instead of ImageMagick.
