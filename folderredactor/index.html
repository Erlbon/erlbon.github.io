The Ⅎolder Redactor

A free tool for the folders of a music or video library: it drafts the short Markdown folder notes a media server shows, and writes only what you say yes to.

Download latest release View source on GitHub

What it does

The other Redactors edit what is written inside your files. The Ⅎolder Redactor works one level up, on the folders: it writes a small Markdown note into a folder that says what is in it (an artist’s introduction, an album’s release, a series’ overview), the notes the Pluteus library server shows. It is the first release (v0.1, build 2026-11-08#05): folder notes for music and video libraries. The second job, checking a library’s folder tree against its own conventions and proposing renames, is not built yet; its Clean Up menu is shown greyed.

Into a library it writes .md folder notes and nothing else. Its settings, caches and history live next to the program.

Features

  • Music notes (moved here from the ɯP3 Redactor): artist.md in an artist’s folder, album.md in an album’s, and about.md in a genre or collection folder (compilations, soundtracks). The tags are read from MP3, FLAC, M4A (AAC and ALAC), Ogg Vorbis and Opus files; MusicBrainz, Discogs and Wikipedia fill in the rest, and a match is checked against the albums really in the folder.
  • Video notes (moved here from the Ʌideo Redactor): series.md in a series folder and about.md in a film’s, from TMDB, with a Wikipedia introduction only when Wikidata links the article to the title. Films in any common container count (MP4, MKV, AVI, MOV, WMV, WebM, MPG, TS and more); the program only counts them, it never opens one.
  • Reviewed yes/no: Notes > Create Notes shows every draft on one review page, with the sources and the reasons for each, and a Before / After view for a note that is already there. Nothing is written without a tick. A note a person edited, or one this program did not write, is never replaced.
  • Where the artists are: a genre or collection about.md says how the folders below it are laid out (layout: letter/artist/album, country/artist/album, album), so Pluteus finds the artists and albums without building an index. A box set whose albums sit in disc folders gets one album.md.
  • Undo: a replaced note goes to the Recycle Bin, and Tools > History (opt-in, off by default) can take every written note back, even after the program was closed.
  • From the old apps: File > Import takes over the ɯP3 and Ʌideo Redactors’ notes settings and lookup answers. API keys (a Discogs token, a TMDB key) are the Redactor family’s shared ones, kept in your operating system’s credential store (Tools > API Keys).
  • Progress for everything slow: folder scans and lookups show a progress dialog.

Where the notes come from

First from your files: their names, folders and tags. Online sources are asked only when you create notes, and every result is reviewed before it is written. With the lookup cache switched on (Tools > Preferences), an answer is kept so the next run does not ask again.

SourceWhat it providesWhat you need
MusicBrainz Artists and releases: names, years, release groups; covers from the Cover Art Archive. Nothing.
Discogs Releases MusicBrainz does not know, and artist profiles. Your own free Discogs token (optional).
Wikipedia and Wikidata The introductions of artist, genre, series and film notes; each note links to its article. Wikidata ties the articles to the other sources. Nothing.
TMDB Series and films: title, year, overview, genres. Your own TMDB API key (needed for video notes).

Command line

The same program runs from a terminal or a script: folderredactor.exe notes PATH drafts the notes of a music or video library and, with --write, writes them (the review is then yours to do first, with the report). Without --write it only reports. --json, --output FILE and --quiet work as in the other Redactors; --update also lists notes made by an older version.

folderredactor.exe notes "D:\Music\0 - Bands" --kind artist
folderredactor.exe notes "D:\Films" --json --output "%TEMP%\notes.json"

The program is a windowed one, so an interactive shell does not wait for it; for scripts ask for the result in a file and wait for the process, as the full reference shows.

Requirements

Windows, 64-bit. Two downloads on each release: folderredactor-setup.exe installs it for you alone (no administrator rights, a Start menu entry), and folderredactor.exe is one file to run from anywhere. Both update themselves through Help > Check for Updates. No Python install needed. There is no Linux download yet. The changelog is in the GitHub repository.
